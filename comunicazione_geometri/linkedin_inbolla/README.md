# LinkedIn InBolla

Materiale iniziale per creare una pagina LinkedIn ex novo e avviare la comunicazione verso geometri e studi tecnici.

File principali:

- `strategia-linkedin-inbolla.md`: struttura pagina, keyword, messaggi, calendario editoriale, copy dei post e messaggi lead generation.
- `assets/post-01.png` ... `assets/post-10.png`: visual quadrati 1200x1200 pronti come prima base grafica.
- `tools/generate_linkedin_assets.py`: generatore dei visual, utile per modificare testi e rigenerare le immagini.
